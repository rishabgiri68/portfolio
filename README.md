# RKG — Player One

A neon pixel-art portfolio for **Rishab Kumar Giri**, featuring AI, machine learning, IoT, and full-stack projects.

Built with HTML, CSS, and vanilla JavaScript. The website runs without a package manager, build step, API key, or backend.

## Features

- Game-inspired start screen and animated section banners.
- Interactive handheld-console profile with three player screens.
- Skills inventory and education information.
- Project cards with accessible mission-detail dialogs.
- GitHub and LinkedIn profile links.
- Responsive desktop and mobile layouts.
- Keyboard navigation, visible focus indicators, and reduced-motion support.
- Locally hosted pixel font and scenery artwork.

## Run locally

From the repository root, start a static server:

```sh
python -m http.server 8000 --directory dist
```

Open [localhost:8000](http://localhost:8000) in a browser. If your system uses `python3`, substitute it for `python`.

You can also open `dist/index.html` directly for a quick preview.

## Files

| Path | Purpose |
| --- | --- |
| `dist/index.html` | Portfolio content, navigation, project cards, and dialogs |
| `dist/style.css` | Theme, responsive layout, typography, and animations |
| `dist/app.js` | Profile-console controls and mission-dialog content |
| `dist/pixel.ttf` | Local pixel display font |
| `dist/pixel-world-empty.png` | Pixel-art hero scenery |
| `make_font.py` | Optional script for regenerating the display font |

The files in `dist/` are the authored website source and must remain version-controlled.

## Customize

- Edit profile information, skills, education, and project-card summaries in `dist/index.html`.
- Edit detailed project descriptions and console screens in `dist/app.js`.
- Adjust colors through the CSS variables at the beginning of `dist/style.css`.
- Update profile links in both the HTML and JavaScript if changing the account owner.
- Keep asset URLs relative so the site works beneath a repository subpath.

The former draggable character and black-hole controls have been removed.

## Hosting

Serve `dist/` as the website's public directory. No compilation or server-side runtime is required.

The existing Sites deployment is owner-private. Uploading this repository does not automatically make that deployment public or enable GitHub Pages.

## Optional font generation

The font is already included, so this is only needed when changing its glyphs:

```sh
python -m pip install fonttools
python make_font.py
```

## Checks

```sh
node --check dist/app.js
```

Before publishing changes, check the page at desktop and mobile widths, open each mission dialog, try the console buttons, and confirm the external profile links. Node is needed only for the optional JavaScript syntax check.
